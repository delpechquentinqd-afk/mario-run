Mario Run EPS · PWA V131.52 — fiches PDF A4 harmonisées

MODIFICATIONS
- Un moteur PDF A4 commun pour toutes les fiches : objectifs, groupes, intensité, relevés et observation (vierges ou remplis), notes et évaluations.
- Nouvelle action « PDF A4 · Séance complète » pour combiner les objectifs et les groupes dans un seul PDF multipage.
- Export PDF A4 accessible également depuis les anciens aperçus de fiche.
- Noms de fichiers PDF explicites selon le type de fiche.
- Génération multipage optimisée pour l'iPad : chaque page est encodée en JPEG puis le bitmap Canvas est libéré avant de préparer la suivante.
- Une section de fiche = une page A4 (210 × 297 mm), même pour les documents multipages.
- Conservation intégrale des classes, séances, protocoles, données IndexedDB et fonctions pédagogiques.

INSTALLATION GITHUB
1. Télécharger et décompresser le paquet Mario_Run_V131_52_Update_GitHub.zip.
2. Téléverser les sept fichiers à la racine du dépôt mario-run, remplacer les versions précédentes.
3. Attendre le succès de GitHub Pages puis vérifier PWA V131.52 dans Mario Run.
4. Tester le PDF de la fiche Objectifs, puis la fiche Relevés et la fiche Notes sur l'iPad.

CONSEIL : sauvegarder les données de classes en JSON avant mise à jour.
